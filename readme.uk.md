# 🟡 Svitlo.live Telegram Bot & HA Integration

[READ IN ENGLISH](https://github.com/chaichuk/svitlo_live/blob/main/README.md)

Цей репозиторій містить **Telegram-бота** для відстеження графіків відключень електроенергії в Україні та **інтеграцію для Home Assistant**.

## 🤖 Telegram Бот (Корінь)
Основним компонентом цього репозиторію тепер є Telegram-бот, який сповіщає користувачів про зміни в графіках.

### Можливості
- ✅ **Сповіщення в реальному часі** про оновлення графіків.
- ✅ **Візуальні графіки**, що генеруються як зображення.
- ✅ **Підтримка багатьох регіонів** (Київ, Дніпро, Одеса, Львів та інші).
- ✅ **Просте налаштування** через інтерфейс Telegram.

### Встановлення та запуск
1. Клонуйте репозиторій разом із субмодулями:
   ```bash
   git clone --recursive https://github.com/rashevskyv/svitlo_if_bot.git
   ```
2. Створіть файл `.env` на основі `.env.example` та додайте свій `BOT_TOKEN`.
3. Запустіть бота:
   - **Windows:** Двічі клацніть на `run.bat` або запустіть `.\run.bat` у терміналі.
   - **Linux:** Запустіть `./run.sh`.

## 🏠 Інтеграція Home Assistant (`external/svitlo_live/`)
Ядро логіки та інтеграція HA знаходяться в репозиторії [svitlo_live](https://github.com/chaichuk/svitlo_live), який додано сюди як git submodule у папку `external/svitlo_live/`.

### Можливості
- ✅ Показує **поточний статус** світла (`Є / Немає`).
- ✅ Визначає час **наступного вмикання** та **відключення**.
- ✅ **Розумне кешування** та **точні таймери**.
- ✅ **Сумісність з HACS** (потребує ручного перенесення або симлінку).

### Встановлення через HACS
1. Додайте цей репозиторій як **Custom Repository** в HACS.
2. Завантажте інтеграцію.
3. **Примітка:** Оскільки інтеграція знаходиться в субмодулі, вам може знадобитися вручну скопіювати папку `external/svitlo_live/svitlo_live` у вашу директорію `custom_components/`, якщо HACS не обробить структуру автоматично.
